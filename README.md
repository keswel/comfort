# comfort

Small, everyday challenges for building discomfort tolerance. Covers social situations, sensory experiences, uncertainty, and unfamiliar environments.
![editcomfortgif](https://github.com/user-attachments/assets/fd22de9c-c3f1-4eeb-9d84-c7813ab2274f)

## Stack

- React Native + Expo
- expo-haptics
- lucide-react-native

## Setup
```bash
npm install
npx expo start
```

Scan the QR code with Expo Go.

## Project Structure
```
├── App.js
└── components/
    └── AffirmationBox.js
```

## Challenge Categories

- **Social** — low-stakes interactions with strangers or service workers
- **Uncertainty** — letting go of control or planning
- **Unfamiliar** — new places and environments
- **Sensory** — tolerating uncomfortable sensory input

## Features

- never repeats the same challenge back-to-back
- category label + color on each card
- streak counter for completed challenges
- haptic feedback
- fade transition between cards

Still a work in progress...
